# .github

The Colorado Startups organization's `.github` repository. It holds the organization's profile page and the CI tooling its repositories share.

| Path | What it is |
|---|---|
| [`profile/`](profile/README.md) | The organization's profile page |
| [`cloud-test/`](cloud-test/README.md) | The tool behind the shared cloud-test workflow, which runs a repository's tests on hosted runners |
| [`ci-pool/`](ci-pool/README.md) | The meter for the organization's pool of free CI minutes |
| `workflow-templates/` | The cloud-test caller a repository copies |
| `.github/` | The shared workflows, the setup action and this repository's own checks |
