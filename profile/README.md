# Colorado Startups

Colorado Startups is a community of founders building companies in Colorado.

Founders come first. Talent, capital and service providers are welcome too.

[![Map of Colorado with the three Colorado Startups regions: Fusion Canyon, Photon Mountain and Space Peak](https://coloradostartups.org/maps/colorado.svg)](https://coloradostartups.org/regions/)

| Region | Cities | Its repo |
|---|---|---|
| [Photon Mountain](https://coloradostartups.org/regions/photon-mountain/) | Boulder, Golden, Arvada, Denver | [photon-mountain](https://github.com/Colorado-Startups/photon-mountain) |
| [Fusion Canyon](https://coloradostartups.org/regions/fusion-canyon/) | Fort Collins, Loveland, Windsor | [fusion-canyon](https://github.com/Colorado-Startups/fusion-canyon) |
| [Space Peak](https://coloradostartups.org/regions/space-peak/) | Colorado Springs, Fountain | [space-peak](https://github.com/Colorado-Startups/space-peak) |

Each region's line follows named roads and is about the size of Silicon Valley. The data is open: [`data/geo/`](https://github.com/Colorado-Startups/coloradostartups.org/tree/main/data/geo).
